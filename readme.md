# 套利程序 for qqqqqf

### 这是一个基于Python + C++(dll)的自动套利程序  
 * 控制基于TGBOT
 * 其中图构建(三角套利等)和大量计算均使用C++完成  
 * 单次循环在7600x测试机上可以做到6ms(不包含网络,盯着300个币,最差情况50w个边的状态)  

> C++部分占比没那么高,我上传的时候上传了一些怪东西  

### 首次使用
 * 需要更改主py文件的79-87行的所有API  
 * 然后运行
```bash
pip install -r "requirements.txt"
python arbitrage_recode.py
```
